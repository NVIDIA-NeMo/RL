# Design and bug patterns

Recurring bug and design shapes worth checking on every PR (beyond TEST A–F).

- ★ **For a new opt-in feature or guard, build the full table: every entrypoint that reads the flag × every format/estimator/backend, check the guard's call site sees each case, and put it at the shared choke point.** `grpo_sync` silently skipped the feature (#2971); gdpo crashed after rollouts (#4326). Details: [trace-the-feature-across-every-entrypoint-and-format](details/trace-the-feature-across-every-entrypoint-and-format.md).
- ★ **For a literal list of names, find what it mirrors and derive it (`fields(X)`, `model_fields`, enum members); a moved list counts as new; if a consumer keeps name rules for a producer's values, have the producer declare them.** Seven cases (#3369, #4052, #4326, #4068). The mirrored-constant part is TEST E. Details: [derive-key-lists-dont-restate-them](details/derive-key-lists-dont-restate-them.md).
- **When a fix touches one arm of an if/elif, read the other arms and check whether the root cause keys off the branch condition.** vLLM decides `is_fused` from tensor rank, so both arms broke (#3280). Details: [partial-fix-check-the-sibling-branch](details/partial-fix-check-the-sibling-branch.md).
- **When a new path writes directly into a library's internals, diff its guard list against the existing sibling path.** The NIXL path rejected EPLB; the new one did not (#2971). Details: [compare-guards-with-sibling-bypass-path](details/compare-guards-with-sibling-bypass-path.md).
- **When N copies of a check become one, diff each deleted copy's message and grep the repo for copies left behind.** The merged example was right only for SFT (#4271).
- **A new mode/backend/transport belongs in the existing selector, not a new boolean elsewhere; a fixed `Literal` of roles should be a name → cluster map.** (#2971, #4465) Details: [new-option-check-existing-selector](details/new-option-check-existing-selector.md).
- **A mode enum plus a dependent knob guarded by a validator usually wants to be one knob.** `max_skipped_prompts: 0` = fail fast (#3470). Details: [collapse-enum-plus-dependent-knob](details/collapse-enum-plus-dependent-knob.md).
- **Before endorsing a new user env var or on/off flag, check whether Slurm or an already-required setting supplies it.** `SLURM_CLUSTER_NAME`; `LOKI_PUSH_URL` set = on (#4375). Details: [infer-from-the-scheduler-before-adding-a-user-var](details/infer-from-the-scheduler-before-adding-a-user-var.md).
- **If a PR keeps an old path behind "size 1 / flag off", mutation-test whether any test still reaches it.** 62/62 tests stayed green with it removed (#4508). Details: [compat-switch-mutation-test-for-one-path](details/compat-switch-mutation-test-for-one-path.md).
- **On a submodule bump, list the attributes upstream newly reads and grep NeMo-RL for a writer.** LR restarted from warmup on every Megatron resume; no CI lane resumes (#4363). Details: [bump-review-trace-upstream-reads-of-state-rl-never-writes](details/bump-review-trace-upstream-reads-of-state-rl-never-writes.md).
- **TEST F covers more shapes than a name list: one class's special fields on a shared RPC/outcome type, a caller re-doing one class's math, or a per-name list of each class's inputs; the fix is the class exposing it through one common interface.** (#4068) Details: [capability-belongs-on-the-class](details/capability-belongs-on-the-class.md).
- **A perf PR must report the deciding numbers; check what its benchmark script actually times.** The scripts on #4508 timed TransferQueue, not the PR's path. Details: [perf-pr-ships-tools-not-numbers](details/perf-pr-ships-tools-not-numbers.md).
- **A mechanism with no precedent in the repo should first try the existing way; name the precedent's path in the ask.** (#3613)
